## Stack

Next.js (App Router) + JavaScript + Tailwind CSS. Edit `app/`, `components/`, and `lib/`.

## Preview locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000

## Deploy after the domain is yours

1. Buy hybridspan.io (links in `brand/DOMAIN-AND-HANDLES.md`).
2. Deploy to Vercel or Cloudflare Pages from this folder.
3. Attach the custom domain. Inquiries go through the contact form.
